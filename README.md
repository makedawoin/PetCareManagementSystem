
A simple lightweight Java program we built to practice the core basics of Object Oriented Programming (OOP). It models a basic pet with a name, age, and owner.

✨ What Our Code Does
We focused on making our code secure, smart, and flexible:

Data Protection: We kept our variables private so pet details can't be messed with directly. You have to use our getters and setters to access them.

Smart Rules: We built in checks to make sure a pet's age can't be negative (it defaults to 0) and names can't be left completely blank.

Flexible Feeding: We overloaded the feed() method so it changes depending on how much info we give it.
